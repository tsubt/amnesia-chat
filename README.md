# Amnesia Chat

Asymmetrical two-person chat. **D** keeps a normal history. **S** watches their own past dissolve — letter scramble + blur — under D’s control.

The server is a tiny WebSocket relay only: room create/join and opaque encrypted frames. No message database.

## Quick start

```bash
npm install
npm run dev:server   # terminal 1 — ws://localhost:8787
npm run dev:web      # terminal 2 — http://localhost:5173
```

1. Open the web app → **Start as D**
2. Share the code, copy-link, or QR with S
3. S opens the invite link (includes the encryption key) and chats
4. D tunes amnesia on/off, clear-word window, scramble, and blur

## Architecture

| Piece | Role |
| --- | --- |
| `apps/web` | Vite + React client (history, amnesia UI, AES-GCM) |
| `apps/server` | In-memory room map + WS fan-out |

Session encryption key is generated by D in the browser and carried in the invite URL fragment (`#k=`), so it is not sent to HTTP servers as a query param. The relay never sees plaintext.

Refreshing as D uses `/session/:CODE#k=...` and rejoins the same room if it still exists in relay memory.

### Frame types (v1)

- `chat` — committed message  
- `settings` — amnesia config from D → S  
- `presence` — peer ready  
- reserved for later: `draft`, `draft_flush` (live typing)

## Deploy (tiny footprint)

The relay needs no database and typically tens of MB of RAM.

**Server (example: Railway / Fly / Render)**

1. Deploy `apps/server` with start command: `bun run src/index.ts` (or `npm start` after installing Bun/Node)
2. Set `PORT` from the host (default `8787`)
3. Ensure WebSocket support is enabled

**Web**

1. Build: `npm run build` (from repo root or `apps/web`)
2. Host `apps/web/dist` on any static host
3. Set `VITE_WS_URL=wss://your-relay.example.com` at build time

Example:

```bash
cd apps/web
VITE_WS_URL=wss://amnesia-relay.up.railway.app npm run build
```

Rooms live in memory. Empty rooms are removed; idle rooms with no sockets expire after 24h. D’s plaintext history is in `localStorage`. S only caches mangled display text. The invite key in `#k=` is not sent to static hosts as a query string.

## Scope

**Now (A):** join via code/QR, chat, S amnesia, D controls, local history, encrypted relay.

**Later (B):** live-stream S’s composer to D; auto-flush draft when D sends.
